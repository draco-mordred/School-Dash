# I.A.N. — Interface & Analytics Subsystem

This internal module owns the dashboard and portal experience orchestration, including role-based summaries and reporting data.

Primary responsibilities:
- role-specific dashboard payloads for admins, teachers, students, and clinical staff
- aggregated reporting across attendance, timetables, exams, and clinical rotations
- activity feed generation and metric consolidation
- portal-level experience orchestration and analytics delivery
